# RFM Segmentation & Cohort Retention

Source: [E-Commerce Data (UK online retailer)](https://www.kaggle.com/datasets/carrie1/ecommerce-data) (~500k transactions, 2010-2011)

## Goal
Deliberately messy real transactional data (negative quantities/returns, missing customer IDs, cancelled invoices, duplicates). Clean it, then build RFM (Recency/Frequency/Monetary) customer segments and monthly cohort retention curves, tying each segment to revenue contribution.
