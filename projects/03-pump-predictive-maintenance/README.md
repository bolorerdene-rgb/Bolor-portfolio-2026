# Predictive Maintenance: Sensor Drift Before Failure

Source: [pump_sensor_data](https://www.kaggle.com/datasets/nphantawee/pump-sensor-data) (~1 year of minute-level readings, dozens of sensors, machine status label)

## Goal
Identify which sensor drift patterns precede a "broken" status and how much warning window they give. Framed as a business analysis (downtime cost avoided), not a pure ML accuracy exercise. Draws on prior hands-on experience as a service engineer on Grundfos pumps.
