# Delivery Performance vs. Customer Satisfaction

Source: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (~100k orders, 2016-2018, 9 normalized CSVs)

## Goal
Join orders → reviews → sellers to compute the gap between actual and estimated delivery dates, then show how late delivery drags review scores down by product category and customer region. Build out as a Power BI star schema / dashboard.
